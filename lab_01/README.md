# Лабораторная работа №1

Вариант 5. Реализация динамического массива целых чисел на C++.

Поддерживаемые операции:

- создание и удаление массива;
- изменение размера;
- вставка и удаление элементов;
- сортировка подсчётом значений от 0 до 1023;
- подсчёт элементов в заданном диапазоне.

## Сборка

Команды выполняются из корня репозитория:

```bash
cmake -S lab_01 -B lab_01/build
cmake --build lab_01/build
```

## Запуск программы

```bash
./lab_01/build/lab01_main
```

## Запуск тестов

```bash
ctest --test-dir lab_01/build --output-on-failure
```

Проект использует C++20, CMake и GoogleTest.
