# Лабораторная работа №4

Вариант 8. Плоские многоугольники `Triangle`, `Square` и `Pentagon`. Индивидуальное задание — вычисление периметра.

Поддерживаемые операции:

- вычисление площади, центра и периметра;
- проверка специальных свойств фигур;
- добавление, удаление и просмотр фигур в коллекции;
- сравнение площадей и вычисление суммарной площади;
- очистка коллекции и подсчёт фигур каждого типа.

`Figure` — абстрактный базовый класс с виртуальным деструктором. `FigureCollection` хранит указатели на собственные копии фигур и удаляет их при очистке. Методы, не меняющие объект, объявлены `const`; виртуальные методы позволяют работать с разными фигурами через `Figure`.

Ввод и вывод фигуры через потоки — координаты вершин в порядке обхода. Например, треугольник: `0 0 4 0 0 3`. В меню дополнительно выводятся название, центр и площадь.

## Сборка

Команды выполняются из корня репозитория:

```bash
cmake -S lab_04 -B lab_04/build
cmake --build lab_04/build
```

## Запуск программы

```bash
./lab_04/build/lab04_main
```

## Запуск тестов

```bash
ctest --test-dir lab_04/build --output-on-failure
```

## Запуск с санитайзерами

Для Clang или GCC:

```bash
cmake -S lab_04 -B lab_04/build-asan -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -fno-omit-frame-pointer"
cmake --build lab_04/build-asan
ctest --test-dir lab_04/build-asan --output-on-failure
```

Проект использует C++20, CMake и GoogleTest.
